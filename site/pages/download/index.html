Agentic Design for macOS

Apple Silicon · macOS 14 or later · signed and notarized

Download .dmg .zip

The latest release, from GitHub

Install

  1. Open the .dmg and drag Agentic Design into Applications.
  2. Open it. The onboarding connects your agents (Claude Code, Codex, Cursor and others) in one click.
  3. Updates come on their own: the app checks for them and asks before it restarts.

Agentic Design for Windows Preview

Windows 10 or 11 · 64-bit (x86-64) · Direct3D 12 or Vulkan

Download .zip

From GitHub Releases

Install

  1. Unzip it anywhere, for example into your user folder.
  2. Run agentic-design.exe. The build is not signed yet: if SmartScreen stops it, choose More info, then Run anyway.
  3. Download the next release when it comes out: updates are not built in on Windows yet.

A preview: the editor, the viewer and the MCP server are the macOS app's. Copying images, trackpad gestures and automatic updates are still macOS only.

Agentic Design for Linux Preview

x86-64 · X11 or Wayland · a Vulkan driver

Download .tar.gz

From GitHub Releases

Install

  1. Install GLFW and a Vulkan driver: 
    sudo apt install libglfw3 mesa-vulkan-drivers   # Debian, Ubuntu
sudo dnf install glfw mesa-vulkan-drivers       # Fedora
  2. Unpack and run it: 
    tar xzf Agentic-Design-*-linux-x86_64.tar.gz
./Agentic-Design-*-linux-x86_64/agentic-design
  3. Optional: zenity (or kdialog) for file dialogs, secret-tool to keep the cloud sign-in in your keyring.

A preview: the editor, the viewer and the MCP server are the macOS app's. Copying images, trackpad gestures and automatic updates are still macOS only.
