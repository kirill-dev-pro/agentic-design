Everything your agent needs to design

Agentic Design is a native macOS editor for .pen files. Your agent reads the document, draws into it and screenshots the result over MCP, while you watch and edit the same canvas live.

What it is

A canvas built for agents, and for you

Agents already write code on your computer. Agentic Design gives them a canvas: the same document you edit, drawn natively, with tools made for how agents work.

Native on macOS

Written in Odin and drawn with NanoVG. One small binary: no browser, plugin or server to keep alive.

Agents are first-class users

They read the document, create nodes in the JSON the file stores, and check their work with screenshot and lint.

Free and open

Your designs are plain .pen files on your disk, readable by people, agents and pencil.design.

Design and agent modes

Draw it yourself, or let the agent drive

One switch in the toolbar. Design mode is a full editor in your hands. Agent mode clears the stage: the agent works, you watch every step and take over at any moment.

Design mode

The whole editor is yours: tools, layers, the inspector, components and themes. Agents can still help, but you hold the pen.

Agent mode

Chat with your agent right next to the canvas. Point at what you mean with comments, arrows and areas: the agent sees your marks and edits the design live.

Agents on the canvas

Watch them work

Every agent connected over MCP gets a cursor with its name. It glides to each layer a request creates, changes or deletes, and the layer flashes in the agent's colour.

  • Claude in clay, Codex in green, named from the MCP client
  • Frames marked placeholder glow while an agent works on them
  • A cursor outside the view waits at the edge, pointing the way

Connect

One button to connect

The app is its own MCP server. On first launch the onboarding finds Claude Code, Codex, Cursor and six more clients on your Mac, and each one connects with a single click.

Your files

Opens Pencil and Paper files

Bring the designs you already have. Files from Pencil (.pen) and Paper open as they are, your agent edits them, and nothing it does not understand is lost on save.

  • Frames, groups, shapes, paths, text and Lucide icons
  • Flex layout: gap, padding, fit and fill
  • Variables, theme axes and per-frame themes
  • Components, instances, overrides and slots
  • Gradients, several fills and shadows, blurs
  • Unknown properties kept as they are

Cloud

Share a link, design together

Upload a file to your cloud in one click. Send a link to view it, or invite people as editors and work on the same canvas live.

  • Private by default, a link or public when you choose
  • Allow download and embedding per link
  • Viewers and editors, changes appear live for everyone
  • Cloud files sit next to local ones on the dashboard
