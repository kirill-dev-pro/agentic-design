What it is

A canvas built for agents, and for you

Agents already write code on your computer. Agentic Design gives them a canvas: the same document you edit, drawn natively, with tools made for how agents work.

Native on macOS

Written in Odin and drawn with NanoVG on Metal. One small binary: no browser, plugin or server to keep alive.

Agents are first-class users

They read the document, create nodes in the JSON the file stores, and check their work with screenshot and lint.

Free and open

MIT licensed. Your designs are plain .pen files on your disk, readable by people, agents and pencil.design.

Agents on the canvas

Watch them work

Every agent connected over MCP gets a cursor with its name. It glides to each layer a request creates, changes or deletes, and the layer flashes in the agent's colour.

  • Claude in clay, Codex in green, named from the MCP client
  • Frames marked placeholder glow while an agent works on them
  • A cursor outside the view waits at the edge, pointing the way

.pen files

An open format, in the app and in the browser

Documents are pencil.design .pen files: plain JSON on your disk. Open one in the browser viewer, or try the editor (beta); the app keeps every property it does not understand, so files round-trip.

  • Frames, shapes, text, icons, components, variables and themes
  • Flex layout: gap, padding, fit and fill
  • Open any file in the viewer at /view, edit it at /edit (beta)

MCP

One command to connect

agentic-design mcp is a stdio MCP server. It forwards tool calls to the running window and opens the window itself when it is closed. The onboarding registers it with Claude Code, Codex, Cursor and six more clients in a click.

get_guide
What the document holds and how its parts are named
batch
Several edits as one undo step, all or nothing
screenshot
A node, the canvas or the whole window, in any theme
lint
Hard-coded colours, missing fonts, text that does not fit
set_variables
Tokens, theme axes and the theme shown
export_code
HTML + CSS or React + Tailwind for the page

Run it on your Mac

Signed and notarized by Apple, for Macs with Apple Silicon on macOS 14 or later. The app keeps itself up to date, and the onboarding connects your agents.
