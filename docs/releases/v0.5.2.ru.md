Agentic Design 0.5.2: гораздо меньше нагрузки на процессор, пока работает агент.

## Fixed
- Приложение больше не загружает ядро процессора, пока агент работает с большим файлом.
  Раньше каждый вызов агента полсекунды перерисовывал холст на полной частоте, и на большом дизайне работа агента держала процессор на 50–100 %. Теперь вызов рисуется один раз, а курсоры агентов двигаются с частотой, которую файл выдерживает: около 10 % на том же дизайне.
