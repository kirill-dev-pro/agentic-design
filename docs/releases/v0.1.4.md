Agentic Design 0.1.4: a "What's new" sheet after each update. Requires a Mac with Apple
Silicon and macOS 14 or later; signed with a Developer ID and notarized by Apple. Installed
copies update themselves.

## New
- What's new, after every update.
  The first launch after an update lists what changed since the version you had, every skipped version included. The app menu and Settings → Updates open it again.

## Improved
- Scripts can tell the MCP server not to start a window.
  `agentic-design mcp --no-launch` (or `AGENTIC_NO_LAUNCH=1`) reports that no window is open instead of opening one; agents keep starting the app when they first need it.
