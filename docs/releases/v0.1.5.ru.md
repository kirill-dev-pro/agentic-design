Agentic Design 0.1.5: все макеты на Mac в разделе Dashboard и Share по ссылке.

## New
- Dashboard показывает все файлы .pen на вашем Mac.
  «All files» находит их через Spotlight и тихий обход домашней папки, новые сверху; сортировка по изменению, открытию, имени или дате создания и поиск по имени. В «Recents» остаются файлы, которые вы открывали в приложении.
- Делитесь файлом по ссылке.
  Кнопка Share в инспекторе входит в аккаунт через браузер (без пароля в приложении), загружает файл с картинками, шрифтами и библиотеками и копирует ссылку, которая открывается в любом браузере. «Upload changes» обновляет файл по той же ссылке; скачивание и встраивание включаются отдельно, ссылку можно выключить.
- Удаление в Корзину прямо с Dashboard.
  Правый клик по карточке или клавиша Delete; сначала спросит, файл можно вернуть из Корзины. «Remove from list» и «Hide this folder» только скрывают файлы.

## Improved
- Превью появляются сами.
  Карточки без превью получают его в фоне, а превью перерисовывается, когда файл меняется.
- «Что нового» теперь по-русски, если Mac настроен на русский.
