Agentic Design 0.7.0: the first builds for Windows and Linux, as a preview.
The macOS app requires a Mac with Apple Silicon and macOS 14 or later; it is signed with a
Developer ID and notarized by Apple, and installed copies update themselves. The Windows
(x86-64, Windows 10 or 11) and Linux (x86-64, X11 or Wayland, needs libglfw3 and a Vulkan
driver) builds are previews: unsigned, without automatic updates. Downloads for every system
are on https://agentic-design.kcrz.dev/download/

## New
- Agentic Design for Windows and Linux, as a preview.
  The same editor, viewer and MCP server as on the Mac, drawn with WebGPU (Direct3D 12 or Vulkan). Copying images, trackpad gestures and automatic updates are still macOS only.
- A download page on the website for each system.
  agentic-design.kcrz.dev/download picks yours and links the newest build for it.
