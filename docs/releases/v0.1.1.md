The first public release of Agentic Design: a native macOS design canvas for .pen files,
built for agents that work on your computer.

- Edit pencil.design `.pen` files directly: frames, flex layout, text, components and
  instances, variables and themes, libraries, gradients, effects, dashed strokes, the pen
  tool.
- A built-in MCP server (`agentic-design mcp`): agents read the document, draw into it,
  screenshot and lint the result while you watch; their cursors show where they work.
- Export HTML + CSS or React + Tailwind (shadcn/ui), PNG, JPEG, WEBP and PDF, with the
  document's open-licensed fonts and its images.
- Updates itself: the app checks GitHub Releases at launch and daily, verifies each update's
  signature and checksum, and installs it when you restart (Settings → Updates).
- The sample design is this app's own landing page.

Requires a Mac with Apple Silicon and macOS 14 or later. Signed with a Developer ID and
notarized by Apple. Source under the MIT license; issues are welcome.
