The first public release of Agentic Design: a native macOS design canvas for .pen files,
built for agents that work on your computer. Requires a Mac with Apple Silicon and macOS 14
or later; signed with a Developer ID and notarized by Apple. Source under the MIT license.

## New
- Edit pencil.design .pen files directly.
  Frames, flex layout, text, components and instances, variables and themes, libraries, gradients, effects, dashed strokes and the pen tool.
- A built-in MCP server for agents.
  Agents read the document, draw into it, screenshot and lint the result while you watch; their cursors show where they work.
- Export HTML + CSS or React + Tailwind (shadcn/ui), PNG, JPEG, WEBP and PDF.
  With the document's open-licensed fonts and its images.
- The app updates itself.
  It checks GitHub Releases at launch and daily, verifies each update's signature and checksum, and installs it when you restart (Settings → Updates).
- The sample design is this app's own landing page.
