Agentic Design 0.5.0: форматированный текст, адаптивный код, наборы иконок и точный экспорт.

## New
- Форматированный текст.
  В одном текстовом слое можно смешивать начертания, размеры, цвета, подчёркивания и ссылки. Агенты пишут его кусками текста; pen.dev по-прежнему показывает простой текст.
- Одна адаптивная страница из кадров для десктопа и мобильного.
  Экспорт кода кадров для разных viewport даёт одну страницу, которая переключается между ними на брейкпоинте, а не страницы друг под другом.
- Иконки приложения и favicon из одного слоя.
  Агенты делают AppIcon для macOS (.iconset и .icns) и набор favicon (favicon.ico, Apple touch icon, веб-иконки); каждый размер рисуется из слоя.
- Прозрачные картинки точного размера.
  В экспорте PNG есть прозрачный фон. Агенты могут запросить картинку точной ширины и высоты, в том числе с прозрачным фоном.
- Поворот вокруг центра.
  Агенты могут поворачивать слой вокруг центра или любой точки; файл остаётся совместимым с pen.dev.

## Improved
- Тени контуров, иконок и текста повторяют их форму, а не прямоугольник.
- Иконки Lucide обновлены до 1.69, старые названия тоже работают.

## Fixed
- Размытие на странице, которую окно не показывает, теперь рисуется в картинках и экспорте.
- Текст мог пропадать в картинках сразу после большого пакета изменений.
- Картинка, которой сначала не было, появляется, когда файл появился; lint называет отсутствующие картинки.
- Картинки внутри папки файла записываются относительно неё, так что папку можно переносить.
