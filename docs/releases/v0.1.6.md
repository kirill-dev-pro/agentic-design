Agentic Design 0.1.6: fixes for the Dashboard, image fills and saved files. Requires a Mac
with Apple Silicon and macOS 14 or later; signed with a Developer ID and notarized by Apple.
Installed copies update themselves.

## Fixed
- New files show up on the Dashboard right away.
  It looks for files again when you come back to it and every minute while it is open, instead of every 10 minutes.
- Image fills in fit mode show the whole image.
  Files that pen.dev saved with the older mode name fit now show the image whole inside the shape, as pen.dev does, instead of cropped.
- Saving a file twice gives the same file.
  A property added by an edit is written where the app puts it on load, so an edited file no longer changes on its next save.
