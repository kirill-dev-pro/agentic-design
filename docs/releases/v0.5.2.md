Agentic Design 0.5.2: much less CPU while an agent works.
Requires a Mac with Apple Silicon and macOS 14 or later; signed with a Developer ID and
notarized by Apple. Installed copies update themselves.

## Fixed
- The app no longer keeps a core busy while an agent works on a big file.
  Every agent call used to redraw the canvas at full rate for half a second; on a large design an agent's run kept the CPU at 50–100 %. Now a call draws once, and agent cursors move at a pace the file can afford: about 10 % on the same design.
