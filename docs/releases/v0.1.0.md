The first release of Agentic Design: a native macOS design canvas for .pen files, built for
agents that work on your computer.

- Edit pencil.design `.pen` files directly: frames, flex layout, text, components and
  instances, variables and themes, libraries, gradients, effects, the pen tool.
- A built-in MCP server (`agentic-design mcp`): agents read the document, draw into it,
  screenshot and lint the result while you watch; their cursors show where they work.
- Export HTML + CSS or React + Tailwind (shadcn/ui), PNG, JPEG, WEBP and PDF.
- Updates itself: the app checks GitHub Releases at launch and daily, verifies each update's
  signature and checksum, and installs it when you restart (Settings → Updates).

Requires a Mac with Apple Silicon and macOS 14 or later. This build is not notarized yet:
the first time, open it with right-click → Open, or allow it in System Settings → Privacy &
Security. Updates install without that step.
