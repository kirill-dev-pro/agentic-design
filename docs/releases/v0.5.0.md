Agentic Design 0.5.0: rich text, responsive code, icon sets and exact exports.
Requires a Mac with Apple Silicon and macOS 14 or later; signed with a Developer ID and
notarized by Apple. Installed copies update themselves.

## New
- Rich text.
  One text layer can mix weights, sizes, colours, underlines and links. Agents write it as runs of text; pen.dev still shows the plain words.
- One responsive page from desktop and mobile frames.
  Export code of frames for different viewports gives one page that switches between them at the breakpoint, instead of pages stacked one under the other.
- App icons and favicons from one layer.
  Agents can make a macOS AppIcon (.iconset and .icns) and a favicon set (favicon.ico, Apple touch icon, web icons), every size drawn from the layer.
- Transparent and exact-size images.
  Export has Transparent background for PNG. Agents can ask for a picture of an exact width and height, and with a transparent background.
- Turn a layer around its centre.
  Agents can rotate a layer about its centre or any point; the file stays compatible with pen.dev.

## Improved
- Shadows of paths, icons and text follow their shape instead of their box.
- Lucide icons updated to 1.69, with their old names still working.

## Fixed
- Blur on a page the window is not showing is now drawn in pictures and exports.
- Text could go missing in pictures taken right after a large batch of changes.
- An image that is missing at first appears once its file is there, and lint names missing images.
- Images inside the file's folder are written relative to it, so the folder can move.
