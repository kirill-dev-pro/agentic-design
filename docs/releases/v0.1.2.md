Agentic Design 0.1.2: flowcharts, a new icon, and exports that ask where to save.

- **New app icon**, with a version drawn for the smallest sizes in Finder and the menu bar.
- **Exports ask where to save.** PNG, JPEG, WEBP and PDF open the Mac's save panel with the
  layer's name; several selected layers go into a folder you choose, one file each; HTML and
  React exports name their folder. The toast after an export has "Show in Finder".
- **Flowcharts.** Connectors that follow their boxes, go around other boxes and keep their
  labels on the line; arrowheads and other markers; diamonds, ellipses and capsules with text
  inside. A connector tool (C) draws one by dragging from box to box. Files stay plain
  `.pen`: pen.dev shows the same picture.
- **Vector PDF for agents.** `export_pages` writes chosen frames or whole pages into one PDF
  with real, searchable text; `screenshot` with format pdf does the same for one layer. The
  PDF from the Export panel is still an image inside a PDF; a vector one comes next.
- **Small text closer to Chrome**: variable fonts kern at their own weight, lines start on
  Chrome's baseline at fractional positions, and text at fractional sizes (21.6 px) gets its
  own metrics instead of the next smaller size's.
- **Bring to front explains itself** when a layer is already in front inside its group, and
  says which parent to move instead.
- **Dashed strokes survive pen.dev.** The dash pattern now lives in the layer's metadata,
  which pen.dev keeps; older files are converted when saved.
- **Agents edit the document they opened.** An agent's edits go only to the file it opened;
  if the window shows another one (after a restart or a tab switch), they are refused
  instead of landing in it. Agents now start with `open`.

Requires a Mac with Apple Silicon and macOS 14 or later. Signed with a Developer ID and
notarized by Apple. Installed copies update themselves.
