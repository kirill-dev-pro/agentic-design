Agentic Design 0.1.2: flowcharts, a new icon, and exports that ask where to save. Requires a
Mac with Apple Silicon and macOS 14 or later; signed with a Developer ID and notarized by
Apple. Installed copies update themselves.

## New
- Flowcharts: connectors, markers and shapes with text.
  Connectors follow their boxes, go around other boxes and keep their labels on the line. The connector tool (C) draws one from box to box. Files stay plain .pen, and pen.dev shows the same picture.
- A new app icon.
  With a version drawn for the smallest sizes in Finder and the menu bar.
- Agents can export vector PDF with real, searchable text.
  export_pages writes chosen frames or whole pages into one PDF; screenshot with format pdf does the same for one layer.

## Improved
- Exports ask where to save.
  PNG, JPEG, WEBP and PDF open the save panel with the layer's name; several layers go into a folder you choose; the toast after an export has "Show in Finder".
- Small text is closer to Chrome.
  Variable fonts kern at their own weight, lines start on Chrome's baseline, and fractional font sizes get their own metrics.
- Bring to front says when a layer is already in front inside its group, and which parent to move instead.
- Dashed strokes survive pen.dev.
  The dash pattern now lives in the layer's metadata, which pen.dev keeps; older files are converted when saved.

## Fixed
- An agent's edits go only to the document it opened.
  After a restart or a tab switch they are refused instead of landing in whatever the window shows. Agents now start with open.
