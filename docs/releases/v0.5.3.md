Agentic Design 0.5.3: smooth panels and lists on big files.
Requires a Mac with Apple Silicon and macOS 14 or later; signed with a Developer ID and
notarized by Apple. Installed copies update themselves.

## Improved
- The canvas is redrawn only when the design or the view changes.
  Scrolling a list, moving the pointer, hovering, selecting, typing a comment and agents' cursors no longer redraw the whole design. On a 5,800-layer file a frame takes about 2 ms instead of 8, and an agent's run uses under 10 % of a core.

## Fixed
- A hard scroll at the end of the layers list no longer shakes the list.
