Agentic Design 0.4.0: give the agent context, pick up past sessions, and point at things.
Requires a Mac with Apple Silicon and macOS 14 or later; signed with a Developer ID and
notarized by Apple. Installed copies update themselves.

## New
- Attach context for the agent.
  The paperclip in the agent field adds folders (a code repo, docs) and files. The agent may read and search them, and nothing else on your Mac. What you attach is remembered for the file.
- Mark things for the agent.
  The pencil opens marks: a comment on a point, a pen, an arrow, an area and numbered tags. They go with your next request, as a list of the layers they touch and a picture, and are never saved in the file.
- Sessions.
  Every conversation about a file is kept and named by the agent. Open Sessions above the field to go back to one, or start a new one.
- Gemini CLI can be the agent too, next to Claude Code and Codex.
