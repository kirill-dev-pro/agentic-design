Agentic Design 0.6.3: Agent mode is fast again.
Requires a Mac with Apple Silicon and macOS 14 or later; signed with a Developer ID and
notarized by Apple. Installed copies update themselves.

## Fixed
- Agent mode no longer slows the whole app down with a long conversation.
  Every word of the chat looked through all the fonts on the Mac each frame; a long thread took seconds a frame. Now a frame takes about 2 ms, and only the messages in view are drawn.
