Agentic Design 0.3.0: ask an agent right in the app. Requires a Mac with Apple Silicon and
macOS 14 or later; signed with a Developer ID and notarized by Apple. Installed copies update
themselves.

## New
- Ask an agent from the canvas and the Dashboard.
  Type a request in the field at the bottom and press Return: Claude Code or Codex, already signed in on your Mac, works on the design while you watch, and the panel above shows what it does. Stop ends it at once; one ⌘Z or Undo takes back the whole request. ⌘L jumps to the field.
- Start a design from the Dashboard.
  A request there creates a new file in Documents/Agentic Design (or where you say) and opens it.
- Agents can work on files you have not opened.
  They read, change and screenshot another .pen file without taking over your window.

## Fixed
- A click acts once.
  Hiding a panel no longer opens it again at once when the click lands where its corner button appears.
