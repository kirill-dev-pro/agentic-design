Agentic Design 0.5.1: fixes for responsive code and icon export.
Requires a Mac with Apple Silicon and macOS 14 or later; signed with a Developer ID and
notarized by Apple. Installed copies update themselves.

## Fixed
- Responsive code switches between desktop and mobile at the right width.
  A wide frame that is pinned to no viewport, such as a components board, no longer moves the breakpoint.
- Icon export writes into a folder that already exists.
